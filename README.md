# C Language

A collection of C programs created while learning and practicing the fundamentals of the C programming language.

The Repository focuses on understanding how C works at a lower level, especially memory allocation, arrays, pointers, structures, and bit manipulation.

## Topics Covered

* C fundamentals

  * Input and output
  * Data types
  * Strings
  * String manipulation

* Arrays

  * 2D arrays
  * Dynamic arrays
  * 3D dynamic arrays

* Dynamic Memory

  * `malloc()`
  * `calloc()`
  * `realloc()`
  * Dynamic memory for structures

* Pointers

  * Pointer-based array operations
  * Dynamic memory using pointers
  * Pointer allocation for multidimensional arrays

* Structures

  * Structures with dynamic memory allocation
  * User input using dynamically allocated structures

* Bit Manipulation

  * Checking whether a bit is set
  * Counting set bits
  * Reversing bits of a 32-bit unsigned integer

## Example Programs

Some of the programs included in the repository:

* Dynamic 2D and 3D arrays
* Array allocation using `malloc()`
* Dynamic memory allocation using `malloc()`, `calloc()`, and `realloc()`
* Student structures with dynamic memory
* Bit reversal of a 32-bit unsigned integer
* Set-bit counting
* Bit checking
* Basic C string operations

## Technologies

* C
* Standard C libraries
* Dynamic memory management

## Running the Programs

Each `.c` file is a standalone practice program and can be compiled separately.

```bash
gcc filename.c -o program
./program
```

For example:

```bash
gcc Dynamic-2D-array.c -o dynamic_array
./dynamic_array
```

## Purpose

This repository is part of my C programming practice, with a focus on understanding memory, pointers, arrays, structures, and low-level programming concepts.

The programs are written from scratch to build a stronger foundation for systems programming and operating systems.
